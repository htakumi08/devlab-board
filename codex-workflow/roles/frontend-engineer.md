# フロントエンドエンジニアロール

## 重点

- React + TypeScript の正しさ。
- API boundary の扱い。
- loading、empty、error state。
- accessibility basics。
- S3 + CloudFront 向け static build の安全性。

## 触ってよいもの

- `frontend/src/**`
- `frontend/README.md`
- frontend に関係する `docs/api/`、`docs/implementation/`
- `codex-workflow/rules/frontend-react.md`
- `codex-workflow/skills/react-typescript/SKILL.md`

## 触らないもの

- unrelated Go backend internals
- unrelated Terraform modules
- `frontend/node_modules/`
- `frontend/dist/` unless release verification explicitly requires inspection

## 出力

- 変更したファイル
- UI state と API boundary の変更点
- 実行した検証
- 残っている未決定事項
